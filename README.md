# 天问

> 名出屈原《天问》——遂古之初，谁传道之？问天之辞，以典为答。

**尽量还原传统占法的本来流程，以大模型代人任占者之判**：**卦断事，盘论人**。
设计文档见 [DESIGN.md](DESIGN.md)；算法流程图与每一步的典籍依据见
[ALGORITHM.md](ALGORITHM.md)。

古之占者一身兼四事：依法起卦（机械仪程）、循例选文（占法定例）、衡文而断
（活的裁量）、为问者讲释。本品照此分工——前两者由确定性代码循典籍明文机行；
**断与释交给大模型**：如古之占者衡所选原文而下占断，引文逐字校验，占断句句
须标出处（**无据不断**），并以「定例断辞」（自经文断辞字样/庙陷明文机取）为
对照基准——异断必须明据。

**本品不保证灵验。保证的是：**

- **正统**——流程与文本俱出典籍明文：《梅花易数》起数与体用占诀、
  《紫微斗数全书》安星诀与断语，另收《说卦传》《文言》为经传取象与
  释义之资（朱子《易学启蒙》占法与《卜筮正宗》铜钱法留存代码，待可
  输入真实掷象时启用——非古籍明说不用随机数）；解读中每条引文
  逐字校验，校验不过即拒绝输出；
- **有条件的可复现**——起卦、排盘、选文、定例断辞由种子与时刻唯一确定，
  任何人可复算核对；占断出自模型（如古之占者，同问未必同断），每次输出
  附**占断存证**（模型名与输出 SHA-256 摘要）：定种子与存证，即定全局。

不配置大模型时降级为纯定例模式：卦象、原文与定例断辞照常输出。

**单一模式，四样同起**（ALGORITHM.md）：输入固定五项——问什么＋
姓名＋生日＋出生时辰＋性别。问语卦（梅花·书写来意「以其字占之」，
所问不同则卦不同，时辰入动爻）、时间卦（梅花·年月日时起例，论当下
之势）、姓名卦（梅花·字占，论问者之位）、紫微命盘（论秉性禀赋与限运）
同时起，全部确定性、无随机数；**吉凶只从主断一处出**（问具体事→问语
卦主断，问命格/时运→紫微主断），其余占法只作"人的语境"入解读——
结构上杜绝自相矛盾。
输入不全只减少参照（如实说明），不改变流程。输出**结论先行**：先一句
白话结论，再断语，再引原文解释理由。

## 快速开始

### 方式零：网页版（零安装，打开即用）

**<https://ll145.github.io/Zhihu/>** —— 推送 main 后由 GitHub Actions
自动部署（`pages` 工作流）。排盘起卦、断语选取与逐字引文校验全部在
你的浏览器内运行（Pyodide 跑的就是本仓库这份 Python 代码，流程与
命令行版逐字一致）；要大模型解读就在页面里填自己的 OpenRouter API
Key（默认模型 `z-ai/glm-5.3`；「思考力度」默认低——GLM、Qwen 等深思
模型不加限常思考数分钟而超时，可按需调中/高/关）——Key 只保存在本机浏览器
（localStorage），不入仓库，请求由浏览器直达 OpenRouter，不经任何
第三方服务器。首次打开需加载十余 MB 的 Python 运行时（来自
cdn.jsdelivr.net）；此后由 Service Worker 缓存，二次打开快、断网
也能起占（大模型解读除外）。每次占问自动存入本机占问记录
（localStorage，至多 20 条，含追问全文，可一键清除），结果可一键复制。

> 一次性设置：仓库 **Settings → Pages → Build and deployment →
> Source** 选 "**GitHub Actions**"（Actions 令牌无权代建 Pages 站点，
> 须仓库主人点一次），之后每次推 main 自动部署。

### 方式一：直接下载可执行文件（Windows，无需安装 Python）

每次推送到 main 分支，GitHub Actions 会自动打包 Windows 单文件版：
仓库 **Actions** 页 → 最新一次 `build` 运行 → Artifacts → 下载
`tianwen-windows`，解压得到两个文件：

- **`tianwen-gui.exe`（推荐）**：图形界面版。双击打开窗口，输入
  所问之事点「起卦 / 排盘」；命理类问题（命格/时运）用下拉框选好生辰
  （公历年月日、时辰、性别，全为下拉不必手填）即出紫微命盘；点右上
  「设置」填入 OpenRouter API Key 即可启用大模型解读与追问（保存在
  exe 旁的 config.json）。
- `tianwen.exe`：命令行版，用法见下文。

打了 `v*` 标签（如 `v0.1.0`）则会自动发布到 **Releases** 页，从那里下载更方便。

```powershell
.\tianwen.exe -q "近期换一份工作是否合适"
```

要启用大模型解读，把 `config.json`（见下文）放在 exe 同一目录即可
（界面版直接在「设置」里填）。命令行版双击也可运行（交互输入问题）。

### 方式二：源码运行（Windows/macOS/Linux）

需要 Python 3.9+（[python.org](https://www.python.org/downloads/) 安装时勾选
"Add python.exe to PATH"）。在项目目录打开终端（PowerShell 或 cmd）：

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

py -m tianwen -q "近期换一份工作是否合适"

# 图形界面版
py -m tianwen.gui
```

若终端中文显示异常，先执行 `chcp 65001` 切换到 UTF-8。

## 配置大模型解读（OpenRouter）

不配置也能用（输出卦象、原文、结论，只是没有白话解读）。

**首次运行会自动生成 `config.json`**（exe 版在 exe 同目录，源码版在项目
根目录），用记事本打开，填两个字段即可：

```json
{
  "api_key": "在这里填入你的 OpenRouter API Key（形如 sk-or-v1-...）",
  "model": "anthropic/claude-sonnet-5",
  "base_url": "https://openrouter.ai/api/v1",
  "reasoning_effort": "low"
}
```

- `api_key`：在 [openrouter.ai/keys](https://openrouter.ai/keys) 创建；
- `model`：OpenRouter 上的任意模型 ID，默认 `anthropic/claude-sonnet-5`；
- `reasoning_effort`：思考力度 `low`/`medium`/`high`/`none`，默认 `low`
  ——GLM、Qwen 等深思模型不加限常思考数分钟而超时；非思考模型忽略
  此参数，置空串 `""` 则不向接口发送该字段。

也可用环境变量代替：`OPENROUTER_API_KEY`、`OPENROUTER_MODEL`、
`OPENROUTER_BASE_URL`、`OPENROUTER_REASONING_EFFORT`（环境变量优先于
config.json）。`config.json` 已在 .gitignore 中，不会被提交。

## 用法

```powershell
# 单一模式（全五项输入）：问语卦＋时间卦＋姓名卦＋紫微盘同起，主断唯一
py -m tianwen -q "近期换一份工作是否合适" --name 李明 --birth 2000-09-14 --birth-time 午 --gender 男

# 输入不全只减少参照（不起姓名卦/无盘，缘由如实展示），不碍起卦
py -m tianwen -q "所问之事"

# 交互模式：直接运行，逐项询问（回车跳过）
py -m tianwen

# 指定起卦时刻（北京时间；复现旧卦 / 测试用）
py -m tianwen -q "所问之事" --when "2026-08-24 15:30"

# 不调用大模型（结论直取定例断辞）；--full 附卦画与十二宫盘面
py -m tianwen -q "所问之事" --no-llm --full

# 翻书：跨全部典籍关键词检索 / 按书名或编号取全文 / 藏书目录
# 现藏：周易经传（十翼全）、王弼《周易注》、《梅花易数》卷一二、
#       《京氏易传》《火珠林》《黄金策》（六爻典据，暂只供翻检）、
#       《紫微斗数全书》卷一至三（含赋文格诀）
py -m tianwen.corpus 大衍之数
py -m tianwen.corpus --cite 西林寺牌额占
py -m tianwen.corpus --cite xici:shang:9
py -m tianwen.corpus --catalog
```

**时区约定**：程序内所有时刻一律按**北京时间（东八区）**——农历即依
东八区定义。时间起卦的「当前时刻」自动由系统时钟换算为北京时间（在海外
运行与国内同刻同卦，凭证可复现）；`--when` 按北京时间填写；生辰按出生地
钟表时间填写（中国大陆即北京时间，海外出生请先自行换算，程序不作换算）。

**问随便问，类按典分**：问事分类是三级判类——界面类别下拉（默认「自动
判类」）或 `--topic 情感` 手动指定最优先（标注〔用户指定〕）；已配模型
时默认由占者判类（模型只择类不占断，输出标注〔占者判类〕）；判类失败或
未配模型则回落关键词规则（确定性，离线可用）。定类而占本是古法之绪
（《梅花易数》十八占、六爻按类取用神、紫微十二宫），类别只定选文框架；
问题原文仍逐字入问事分宫与占者。

输出**结论先行**（ALGORITHM.md 六）：【结论】白话一两句直接回答所问 →
【断语】传统断辞句（句末标出处——无据不断，异于定例须明据）→
【理由】引古籍原文（逐字校验）并解释 → 【建议】→ 卦盘一览（各占法
一两行：主断/参/语境的分工与定例断辞）→ 所据原文节选（主断附全文，
其余列古籍原名，`corpus --cite 书名` 可随时取全文；含彖象传、
**王弼注**、乾坤《文言》，梅花法另按体用附**《说卦传》广象**、
**体用总诀**与所问类**占章**）→ **占断存证**（模型名与输出 SHA-256）→
起卦/排盘凭证（取数与算式，任何人可复算）。出处一律以古籍原名展示
（如〔《周易·革·九五》爻辞〕）；内部编号（cite_id）只在引文校验层流转。

**体用取象（梅花法）**：依《梅花易数》，动爻所在之卦为用、不动之卦
为体；体用两卦各附《说卦传》第十一章广象（乾为天为圜……）供占者
取象，《体用总诀》全文与所问类别对应之占章（求谋占、婚姻占、出行占
……凡有把握对应者）一并入所据文本。取象与占诀只作解读之资，占断
仍须以卦爻经传之文为据。

命理类问题（命格/时运）提供生辰后走**紫微命引擎**：终端绘十二宫命盘
（主星辅煞、庙旺平陷、四化、大限），断语按规则选自《紫微斗数全书》
（命宫主星论断＋分宫格＋入男/女命诀，另按安命宫支机取**卷一合格诀／
破格诀**为参；时运取现行大限宫主星入限诀，**流年**列太岁与小限
（《安小限诀》）所在之宫、太岁相冲诸项依《论二限太岁吉凶》逐项查验），
结论由庙陷表与《论大限十年祸福何如》明文确定性映射（强/平/弱、顺/中/危），
排盘凭证列明全部流派约定。盘为主断时另设**书桌**：按主断宫主星自卷一
赋文格诀池机械召回候选断语入语境（可引不可断，召回规则进凭证）。
未提供生辰则以问语卦就当下之势作断并说明局限。

**问事分宫**：问运带具体题材（财运、事业运、桃花运……）时，按关键词
规则加取所涉之宫的诸星断语（《全书·卷二》十二宫：财→财帛宫、婚恋→
妻妾宫、事业→官禄宫……），因人因题各异；题材宫只入解读，结论仍单源
自大限/命宫，不出第二个吉凶。

**多占并用而不自相矛盾**（ALGORITHM.md 五）：三种占法同时起，但吉凶
只有一个出处——主断侧产出定例断辞与占断；其余占法的原文以「语境」
身份进入解读（问事时：姓名卦论问者之位、紫微断语论秉性禀赋；问命理
时：时间卦论当下之势），提示词与校验器双重禁止语境立断——校验器
要求断语所据必须落在主断侧文本上。语境引文同样逐字校验。角色分工
（卦断事，盘论人，名论其位）为今法约定，各占法内部逐步有据。

**多轮追问**：在终端交互运行且已配置大模型时，解读输出后可就本卦继续
追问（如"如果拖到年底再动呢"）。追问不重新起卦，回答仍只能依据本次
选定的经文，占断已下不得变更，每轮回答同样经逐字引文校验；直接回车结束。
