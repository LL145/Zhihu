# 知乎 · 算命 Agent

**尽量还原传统占法的本来流程，以大模型代人任占者之判**：**卦断事，盘论人**。
设计文档见 [DESIGN.md](DESIGN.md)。

古之占者一身兼四事：依法起卦（机械仪程）、循例选文（占法定例）、衡文而断
（活的裁量）、为问者讲释。本品照此分工——前两者由确定性代码循典籍明文机行；
**断与释交给大模型**：如古之占者衡所选原文而下占断，引文逐字校验，占断句句
须标出处（**无据不断**），并以「定例断辞」（自经文断辞字样/庙陷明文机取）为
对照基准——异断必须明据。

**本品不保证灵验。保证的是：**

- **正统**——流程与文本俱出典籍明文：朱子《易学启蒙》占法、《梅花易数》
  起数、《卜筮正宗》铜钱法、《紫微斗数全书》安星诀与断语；解读中每条引文
  逐字校验，校验不过即拒绝输出；
- **有条件的可复现**——起卦、排盘、选文、定例断辞由种子与时刻唯一确定，
  任何人可复算核对；占断出自模型（如古之占者，同问未必同断），每次输出
  附**占断存证**（模型名与输出 SHA-256 摘要）：定种子与存证，即定全局。

不配置大模型时降级为纯定例模式：卦象、原文与定例断辞照常输出。

- **易经事引擎（v1）**：问具体一事（换工作、出行……）→ 起卦 → 朱子占法
  选文 → 断辞结论。
- **紫微命引擎（v2）**：问命格、时运 → 依生辰排紫微命盘 → 命宫主星／现行
  大限断语 → 庙陷定强弱。生辰唯一定盘，无随机成分，可用任意通行排盘
  工具交叉核对（流派分歧处已显式标注）。

## 快速开始（Windows）

### 方式一：直接下载可执行文件（无需安装 Python）

每次推送到 main 分支，GitHub Actions 会自动打包 Windows 单文件版：
仓库 **Actions** 页 → 最新一次 `build` 运行 → Artifacts → 下载
`yijing-agent-windows`，解压得到两个文件：

- **`yijing-agent-gui.exe`（推荐）**：图形界面版。双击打开窗口，输入
  所问之事点「起卦 / 排盘」；命理类问题（命格/时运）用下拉框选好生辰
  （公历年月日、时辰、性别，全为下拉不必手填）即出紫微命盘；点右上
  「设置」填入 OpenRouter API Key 即可启用大模型解读与追问（保存在
  exe 旁的 config.json）。
- `yijing-agent.exe`：命令行版，用法见下文。

打了 `v*` 标签（如 `v0.1.0`）则会自动发布到 **Releases** 页，从那里下载更方便。

```powershell
.\yijing-agent.exe -q "近期换一份工作是否合适"
```

要启用大模型解读，把 `config.json`（见下文）放在 exe 同一目录即可
（界面版直接在「设置」里填）。命令行版双击也可运行（交互输入问题）。

### 方式二：源码运行

需要 Python 3.9+（[python.org](https://www.python.org/downloads/) 安装时勾选
"Add python.exe to PATH"）。在项目目录打开终端（PowerShell 或 cmd）：

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

py -m yijing_agent -q "近期换一份工作是否合适"

# 图形界面版
py -m yijing_agent.gui
```

若终端中文显示异常，先执行 `chcp 65001` 切换到 UTF-8。

## 配置大模型解读（OpenRouter）

不配置也能用（输出卦象、原文、结论，只是没有白话解读）。

**首次运行会自动生成 `config.json`**（exe 版在 exe 同目录，源码版在项目
根目录），用记事本打开，填两个字段即可：

```json
{
  "api_key": "在这里填入你的 OpenRouter API Key（形如 sk-or-v1-...）",
  "model": "anthropic/claude-sonnet-5",
  "base_url": "https://openrouter.ai/api/v1"
}
```

- `api_key`：在 [openrouter.ai/keys](https://openrouter.ai/keys) 创建；
- `model`：OpenRouter 上的任意模型 ID，默认 `anthropic/claude-sonnet-5`。

也可用环境变量代替：`OPENROUTER_API_KEY`、`OPENROUTER_MODEL`、
`OPENROUTER_BASE_URL`（环境变量优先于 config.json）。
`config.json` 已在 .gitignore 中，不会被提交。

## 用法

```powershell
# 梅花易数·时间起卦（默认）：完全确定，同一时刻问同一事，任何人复算结果一致
py -m yijing_agent -q "所问之事"

# 铜钱法·六爻：随机种子公开（SHA-256），凭证可复现
py -m yijing_agent -q "所问之事" --method coin

# 指定起卦时刻（北京时间；复现旧卦 / 测试用）
py -m yijing_agent -q "所问之事" --when "2026-08-24 15:30"

# 不调用大模型
py -m yijing_agent -q "所问之事" --no-llm

# 命理类问题（命格/时运）：附生辰走紫微命引擎（缺出生时辰无法排盘）
py -m yijing_agent -q "我今年运势如何" --birth 2000-09-14 --birth-time 午 --gender 男

# 问具体事时附生辰 → 卦盘合参：仍以卦断吉凶，命盘断语只作"人的语境"进入解读
py -m yijing_agent -q "近期换一份工作是否合适" --birth 2000-09-14 --birth-time 午 --gender 男
```

**时区约定**：程序内所有时刻一律按**北京时间（东八区）**——农历即依
东八区定义。时间起卦的「当前时刻」自动由系统时钟换算为北京时间（在海外
运行与国内同刻同卦，凭证可复现）；`--when` 按北京时间填写；生辰按出生地
钟表时间填写（中国大陆即北京时间，海外出生请先自行换算，程序不作换算）。

输出第二行即标明本次所用引擎（「引擎：易经事引擎（卦断事）」或
「引擎：紫微命引擎（盘论人）」），此后包含：问事类别（事业/学业/情感/
出行…，规则分类，决定解读落点）→
卦象（本卦、之卦、互卦、动爻）→ 所据经文（占法规则选定的原文，
含彖、象传与**王弼注**，逐条标出处）→ **定例断辞**（吉/凶/谨/忌…，
自经文断辞字样机取，作对照基准）→ **占断与讲释**（占者：大模型——
衡所据经文而下占断，句末标出处，异于定例须明据；引文逐字校验）→
**占断存证**（模型名与输出 SHA-256）→ 起卦凭证（算式或种子，可自行复算）。

命理类问题（命格/时运）提供生辰后走**紫微命引擎**：终端绘十二宫命盘
（主星辅煞、庙旺平陷、四化、大限），断语按规则选自《紫微斗数全书》
（命宫主星论断＋分宫格＋入男/女命诀；时运取现行大限宫主星入限诀），
结论由庙陷表与《论大限十年祸福何如》明文确定性映射（强/平/弱、顺/中/危），
排盘凭证列明全部流派约定。未提供生辰则退回事引擎论当下之势并提示。

**问事分宫**：问运带具体题材（财运、事业运、桃花运……）时，按关键词
规则加取所涉之宫的诸星断语（《全书·卷二》十二宫：财→财帛宫、婚恋→
妻妾宫、事业→官禄宫……），因人因题各异；题材宫只入解读，结论仍单源
自大限/命宫，不出第二个吉凶。

**卦盘合参**：问具体事（走事引擎）时若附了生辰，命盘会以与所问相应
之宫的断语作"人的语境"进入解读——只说明同一结论落在你的秉性上如何
着力，**不改变卦的断辞**，也不产生第二个吉凶；合参引文同样逐字校验。

**多轮追问**：在终端交互运行且已配置大模型时，解读输出后可就本卦继续
追问（如"如果拖到年底再动呢"）。追问不重新起卦，回答仍只能依据本次
选定的经文，占断已下不得变更，每轮回答同样经逐字引文校验；直接回车结束。

## 项目结构

```
yijing_agent/
  casting.py     起卦引擎：梅花易数时间起卦（无随机数）/ 铜钱法（种子公开）
  selection.py   断卦规则：朱熹《易学启蒙》占法 + 《梅花易数》体用
  verdict.py     断辞 → 定例结论映射（确定性对照基准；人工审定走
                 data/verdict_overrides.json）
  topic.py       问事分类（分类断法）：关键词规则定类别与解读落点，无 LLM
  knowledge.py   典籍知识库：结构化查表（64卦 + 彖传 + 象传，非向量检索）
  llm.py         占断与讲释（OpenRouter；占者之断，无据不断，异于定例须明据）
  validator.py   引文校验器：逐字比对＋占断必须标据，防幻觉闸门
  redline.py     红线拦截：医疗/投资/法律/寿夭类问题拒答
  lunar.py       公历→农历（cnlunar），流派约定显式标注
  service.py     双引擎流水线门面（路由/会话/解读/追问，GUI 复用）
  gui.py         图形界面（Tkinter 标准库，打包为 yijing-agent-gui.exe）
  ziwei/         紫微命引擎（v2）：
    chart.py       排盘（安星诀逐条代码化，流派约定显式选定）
    brightness.py  《全书·卷二》庙陷表逐格转录
    knowledge.py   紫微库查表（data/ziwei.json）
    selection.py   断语选取 + 确定性结论（庙陷定强弱、大限论定顺逆；
                   问事分宫、合参语境选文）
    llm.py         命盘解读与追问（复用引文校验管线）
    report.py      终端十二宫命盘图与排盘凭证
  data/          知识库数据与校对说明（见 data/PROOFREADING.md）
                 hexagrams.json 经传原文；wangbi.json 王弼《周易注》；
                 ziwei.json 《紫微斗数全书》断语库（429 条）
tools/
  import_openiching.py        从 open-iching 仓库导入并校验典籍数据
  import_wikisource_wangbi.py 从维基文库《周易正義》导入王弼注（经文锚定对齐）
  import_wikisource_ziwei.py  从维基文库《紫微斗數全書》导入紫微库
  gen_ziwei_fixtures.py       以 py-iztro 生成排盘命例回归集（开发机用）
tests/           165 项测试：起卦确定性、占法七情形、断辞映射、问事分类、
                 注疏挂载、引文校验、LLM 重试与追问；紫微排盘 21 命例
                 回归（对照 iztro）、安星诀明文例、紫微库完整性、选文与
                 结论、问事分宫与合参
```

## 数据与校对

经传原文导入自 [john-walks-slow/open-iching](https://github.com/john-walks-slow/open-iching)
（ISC 许可，经传原文为公版），导入时做了 64 卦 / 384 爻 / 彖象条数与爻画
一致性的完整校验。王弼《周易注》（598 条）导入自中文维基文库
[《周易正義》](https://zh.wikisource.org/wiki/周易正義)（CC BY-SA 4.0，
含维基文库贡献者所加标点；各页面版本号记录于数据文件 meta），以经文
锚定逐段对齐，注疏只作解读语境、不参与断辞结论。《紫微斗数全书》断语库
（429 条）与庙陷表导入自中文维基文库
[《紫微斗數全書》](https://zh.wikisource.org/wiki/紫微斗數全書)卷一至卷三
（CC BY-SA 4.0 同上）；排盘安星诀逐条注于源码，命例回归集对照 iztro
排盘库（流派分歧处如实标注并按底本实现）。以上**均尚未依通行本人工
校对**——校对流程与状态见
[yijing_agent/data/PROOFREADING.md](yijing_agent/data/PROOFREADING.md)。
